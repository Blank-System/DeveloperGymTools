# Modular Developer Gym
A simple, modular tool for creating and displaying development content, standard metrics, and more in a consistent format that is accessible for developers and designers.

## Features
- Gym Section
  - Title
  - Colour
  - Dimensions
- Gym Height
  - Pulls height automatically
  - Optional short context string
  - 3 Styles
    - Over (Platform)
    - Over (Solid)
    - Under
- Gym Angle
  - Set Angle
  - Optional short context string
- Gym Width
  - Set Width
  - Optional short context string
- Gym Trigger
  - Abstract trigger section
  - Open Level Trigger
  - Teleport Trigger
